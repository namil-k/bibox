# copy-citation

Press `Y` on an entry (or a multi-selection), pick APA, IEEE or Chicago, and the formatted citation lands on the clipboard. With several entries selected you get one citation per line. Needs a clipboard command on PATH: `pbcopy` (macOS), `wl-copy` (Wayland) or `xclip` (X11).

Install: `bibox plugin install namil-k/bibox/plugins/copy-citation`
